1. Craft 的「安静美学」到底美在哪

看图 30 秒，抓 5 条就够了——接下来每一条都对应 onedesktop 的一处病。

Craft 的画面

浅暖灰 canvas、纯白卡片、几乎无阴影、单色线性图标。 整屏就一个彩色点（右下角 Assistant）。

5 大设计要点
  • 中性灰主调，全屏只用 1 处彩色（右下角 Assistant）；其他都是 #1D1D1F / 灰阶
  • 圆角 14-18px，卡片软得像 Mac 原生
  • 阴影极轻，纯靠层级和留白"浮"出来
  • 11-13-15-17 字号，层级克制，不靠"花"字号撑场面
  • 线性单色图标 1.5px stroke，全图统一

2. OneDesktop 现状摸底

基于 8/4 HEAD 代码（`App.css` + `Sidebar.tsx` + `TopBar.tsx`），客观复刻现状。

当前 Token（写死的事实）

维度当前值（App.css）看图感觉

3. 7 个具体差距（按"最显眼"排序）

改了第 1、2 项，立刻能让整屏看起来"贵"一倍。后面的排第 3、4…… 都是必要不紧急。

差距 01 · 最显眼
Logo：渐变填充 + 阴影
现在是 linear-gradient(--accent → --accent-pressed) + box-shadow: var(--shadow-sm)。 像 SaaS 营销页 logo，不像 macOS 原生应用。
改：fill: #0066CC 单色 + 移除 box-shadow + 圆角 6→4 让它"靠色块自描述"。
差距 02 · 最显眼
卡片阴影偏重
--shadow-md: 0 4px 12px rgba(0,0,0,0.08)，所有"浮起来"的地方都很重。 这就是"low"的体感来源之一。
改：只保留 0 1px 2px rgba(0,0,0,0.04) 的极轻投影； 浮起来靠"浅暖灰 canvas + 纯白卡片"的对比，不再靠阴影。
差距 03 · 显眼
卡片圆角偏小
--radius-md: 10px 给聊天消息、按钮，--radius-lg: 14px 给大卡片。 10 在 2026 年看着像"工具软件"，14-16 才像"内容产品"。
改：消息 / 按钮 → --radius-md: 10（保留，给按钮）， 大卡片新增 --radius-card: 16px（替代 14）。
差距 04 · 显眼
背景几乎纯白
内容区是 #ffffff，卡片也是 #ffffff。 没有"底"和"片"之分，所以卡片"飘不起来"。
改：新增 --bg-canvas: #FAFAFC 给内容区； 卡片仍是 --bg-surface: #FFFFFF。靠 1.5% 灰度差把卡片"浮"出来。
差距 05
User 气泡全蓝饱和
.message-bubble.user { background: var(--accent); } 整个屏幕全是高饱和小蓝块，远看像一堆 emoji。
改：保留蓝色 user 气泡做角色区隔，但缩小尺寸（max-width: 70%）+ 收紧内边距 + 让 user 气泡也用 --bg-elevated + 蓝边描线（hybrid）。
差距 06
选中态偏蓝
侧边栏选中 nav / 会话 / 群都用 --accent-soft 蓝色软底。 整屏"哪儿都点过"，过于花哨。
改：选中态改用纯灰底 --bg-hover 或更深一档（如 #EBEBF0）， 让图标和文字"主动变深"承担"选中"语义，不靠蓝色。
差距 07
顶栏左侧偏空 + 不够紧凑
TopBar 现在只有「侧栏开关 + 返回 + 标题」三个元素，左边 1/3 是空的。 顶上看着"没装满"。Craft 这种页是「标题在左 + 右上一排图标」紧凑。
改：顶栏改为「左：drag region；中左：标题；右上：视图切换 / 排序 / 搜索 / 设置」4 个图标， 与 Apple macOS 原生应用风格对齐（更像 Finder / Notes）。

4. 升级原则（守住这 8 条底线）

不论选哪个方案，下面的红线不能跨。

维度原则数值参考
色彩 中性灰主调，主色 ≤5% 面积 #1D1D1F / #6E6E73 / #AEAEB2
背景层 canvas 和 surface 必须有灰度差（卡片才"浮"） canvas #FAFAFC / surface #FFFFFF
字号 10/11/12/13/15/17/20/24px type scale 标题 600 / 正文 400 / 强调 500
圆角 按钮 8-10 / 小卡 10 / 中卡 14 / 大卡 16-18 --radius-{sm/md/lg/xl}
阴影 极轻，浮起来靠 canvas 灰度差而非投影 0 1px 2px rgba(0,0,0,.04) 唯一一档
图标 单色 SVG，统一 1.5-2px stroke，禁用 emoji stroke="currentColor"
间距 8px 网格，gap ≥ 16px --space-{xs/sm/md/lg/xl}
动效 200ms cubic-bezier，仅颜色过渡 不引导 transform / opacity 全局动画

5. V1 ~ V4 升级方案

从"零风险"到"全换装"，四档可选。

V1 · 小修
3 处小动
零风险、立竿见影、1~2 小时。
  • Logo 去渐变去阴影，改为纯色块
  • --shadow-md 改成 0 1px 2px .04
  • 侧栏选中态去掉蓝色软底改纯灰
风险：极低预计：1 PR
V2 · 中修 · 推荐起点
V1 + 关键组件升级
一天能做完，整屏"换光"，是性价比最高的一档。
  • V1 全部 3 条
  • 新增 --bg-canvas #FAFAFC，主区背景用 canvas
  • 侧栏背景保留 --bg-secondary，与 canvas 错层
  • 卡片圆角 14 → 16；新增 --radius-card: 16
  • User 气泡 max-width 70% + 缩内边距
  • TopBar 重排：drag region / 标题居中 / 右上 4 图标
  • 主标题字重 700 → 600，更克制
风险：中预计：1 PR + 1 个 handoff
V3 · 大改
设计系统重设
App.css 全量改写、token 全调、所有组件过一遍。
  • V2 全部
  • 所有间距、圆角、字号集中对齐到 8px / 4px 倍数
  • 所有面板 / 抽屉 / 弹窗统一阴影为极轻一档
  • 图标库收敛到统一 1.5px stroke 集
  • logo / favicon / 启动屏一并换肤
  • 设计 token 输出 CSS 变量 + 设计稿
风险：整窗一次变预计：2-3 PR
V4 · 渐进 · 推荐路径
先 V1 → 再 V2 → 按需 V3
分三次走，每一步都可回滚、可对比、可让团队对齐审美。
  • 第 1 步：V1（1 天）—— 立竿见影跑通
  • 第 2 步：V2（2 天）—— 整屏换光
  • 第 3 步：按需 V3（按组件升级）—— 不一次大改
风险：低预计：3 次小迭代

6. 推荐路径：V4 渐进

节奏就是 ≤ 1 天一档，每档可回退、可对照设计风格清单验证。

Day 0 — V1 小修
Logo / 阴影 / 选中态 三处。1 个 PR，commit message：「chore(ui): apply craft-style bare minimum」。 跑完看一眼，整屏会马上"贵"起来。
Day 1 — V2 中修
引入 --bg-canvas / 大卡片圆角 16 / TopBar 重排 / 主标题字重 600。 这一天不要碰业务逻辑，只动 token + 视觉骨架。
Day 2+ — 按需 V3
看团队反馈决定下一步。如果 ok，到此为止；如果你想要"全方位 Craft 化"，再分组件迭代到 V3 状态。 不会一次性大改、不会翻车。
