Impeccable · extract Apple HIG Tauri2 + React18 + TS 通过抽取现有代码归纳的设计语言，附 Impeccable AI Slop Test 评分与可系统化薄弱点。

0 · 设计上下文（非从代码推断）

谁用 / 在什么情境 / 该有什么感觉

受众：开发者，单机桌面 AI Agent（OneDesktop）做 Agent 协作 / 自动化。
调性：Apple HIG 极简、克制、中性分隔线承重；唯一功能蓝 #006edb；至多一个去饱和信号色（错误暖陶土 #a85c3c）；禁用彩色 emoji、单色 SVG 图标。
约束：纯本机 SQLite、无服务端/账号；亮/暗双主题同源切换；a11y 视为硬约束（WCAG AA 4.5:1 写进注释与 token 命名）。

1 · Token 体系（单一来源 src/App.css）

原生 Apple 系统色为 source of truth，v2 语义名（--bg-base/--accent-primary/--status-*）仅作别名，保证旧组件不动。这是教科书级的分层：primitive → semantic alias。

排版 / 间距 / 圆角 / 阴影 / 布局

Typography

字体栈 SF Pro / PingFang SC。字号刻度 --text-2xs→--text-3xl（11→40px）。禁止裸 font-size。代码块语法高亮走语义 token（kw=蓝 / str=绿 / num=橙 / cmt=灰）。

Spacing

--space-xs(4) → --space-2xl(32)。轮间 14px 收紧（对齐 iMessage/飞书节奏）。

Radius

sm6 / md10 / lg14 / xl20。气泡用 lg，右下角收 sm 制造"发出"感。

Shadow

sm/md/lg 近不可见（0.04–0.06 alpha）。卡靠 canvas-vs-surface 亮度差"浮起"，不靠阴影重量。

Layout

sidebar 260 / topbar 52 / 控制高 36 / 内容最大 1180 / 弹窗 420·600·900。macOS 红黄绿避让 68px。

Glass

--glass-surface 半透白 + 1px 顶高光 + 柔抬影；@supports backdrop-filter 才启用，否则回退实色。暗主题独立套。

2 · 图标系统（Icons.tsx）

单色 SVG 组件库，统一 1.5px 圆角描边 + currentColor，无填充、无彩色 emoji。按用途分组：

  • 通用/导航：Copy / Refresh / Chevron / Settings(Sliders) / Globe / Palette / User / Bot / Plug / Wrench / Puzzle / Sun / Moon / Search …
  • Process 时间轴专用（16px 画布）：ProcessReasoning / Observation / Command / Edit / Document / Search / Folder / Think / Grep / GenericTool —— "已执行工具"用语义图标而非 + 号。
  • 状态/空态：AlertTriangle / Inbox / Zap / Clock / Stethoscope(能力体检) / Coins(预算护栏) / Ban。
  • 圆桌/作曲家：Paperclip / AtSign / Summarize / Send / Kanban / Deliverables。

设计纪律：图标是"系统表面"的一部分，不是装饰。深度思考图标从 v1"中心射线"（小尺寸酷似加号，被用户否决）迭代为"气泡+三点"。

3 · 组件模式（可复用骨架）

玻璃浮层

输入条 / 侧栏 / 顶栏用 --glass-surface 半透 + blur + 顶高光，在平灰画布上才"读得出"。

气泡

user = 静灰填充(右) / assistant = 白面 + 发丝边(左)。区分靠位置+亮度，不靠蓝。

卡片

1px 发丝边 + 同 surface 底，hover 仅变底；选中用灰底 + 600 黑字（accent 不上此面）。

弹窗/抽屉

role=dialog + useDialogA11y；遮罩 --overlay 禁止写死；宽度走 --modal-width-*。

侧栏导航

图标+文字；激活态浅蓝 pill + 左侧 3px accent 条，文字黑字 600（保 AA）。

状态点

6px 圆点传状态；仅 busy 显"工作中(n)"文字（计数有用）。中性、不喧哗。

4 · 主题与切换

亮/暗仅覆盖原生 token，语义别名自动解析（DRY）。[data-theme-transition] 只对颜色属性做 200ms 缓动，刻意排除 transform/opacity 防重绘闪烁。暗主题纯黑→冷深灰（带蓝相），canvas 比 primary 略深，与亮主题同构。

结论：这项目本身就是"反 AI 味"的正面样本。 它没有紫蓝渐变、三列等宽 Feature Card、玻璃滥用、圆角+发光。它的克制是有意图的（Apple HIG，非收敛默认）。把界面给人看并说"这是 AI 做的"，对方不会立刻信——因为它读起来像原生 macOS 应用。这正好通过 Impeccable 的核心测试："独特的界面应该让人问怎么做出来的，而非哪个 AI 做的。"

6 · Extract 机会（该系统化的薄弱点）

① calendar.css 整片硬编码红 —— #e53935 / #c62828 / #fff !important 出现 ~10 处（事件标记/今日高亮）。绕过 --danger / --status-error / --text-inverse token，暗主题下未重定义会翻车。建议：抽 --cal-event / --cal-today 语义 token，走现有状态色体系。
② 遗留 token 兜底引用 —— var(--color-danger, #e53e3e)(agentPlan.css)、var(--border, #d0d0d5)、var(--accent, #2f6feb)(groups.css)、var(--status-error, #dc2626)(artifacts.css) 引用了 App.css 未定义的旧名。要么补定义、要么改回现行 token。属"假 token"，是系统腐化苗头。
③ 暗主题 diff 行写死 rgba —— run-changeset.css 暗态 rgba(48,209,88,.16)/rgba(255,69,58,.16) 应并入 --cu-green/--cu-* 或新增 --diff-add/--diff-del token。
④ DAG 关键节点写死 signal 值 —— groups.css #a85c3c（3256/3375/3380/3381 行）虽与 --signal 等值，但应直接 var(--signal)，避免日后改 token 不同步。

7 · 关键约定速记

  • 颜色只走 App.css 语义变量；组件禁写死 hex（dark 仅 [data-theme="dark"] 重写）。
  • 禁用彩色 emoji；图标走 Icons.tsx，stroke=currentColor 1.5px。
  • 选中态用黑字 600 + 灰底，禁用 accent 蓝字（保 WCAG AA）。聚焦环用中性加深 --border-focus，不用蓝框。
  • 弹窗 .modal* + role=dialog；两答案出口（AnswerBubble / ProcessPanel）共享 MessageActions。
  • 单一 blue 作功能激活态，屏占比 ≤5%；至多一个去饱和信号色（暖陶土）。
