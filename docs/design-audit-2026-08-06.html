UI / UX 设计审研

OneDesktop 界面设计方案与优化建议

基于当前真实代码（Sidebar / TopBar / ChatArea / InputBar / MessageList 与 App.css 设计令牌）的逐项审查。结论：底层设计语言已相当成熟，问题集中在「信息架构的清晰度」「顶部栏的闲置」与「对话密度」三处，均为低成本高回报的改动。

审阅人：UI Designer · 日期：2026-08-06 · 范围：主框架与对话主屏

一、总体评价

👍 扎实Apple HIG 令牌体系、统一图标、毛玻璃系统、暗色适配均到位，组件不写死。
⚠️ 3 处高影响问题：导航模型重叠、顶部栏空置、对话留白偏松。
🎯 快赢⌘K 命令面板 + 侧栏分组 + 气泡间距微调，半天即可上线。

一句话结论：不应该推倒重来，而是收敛导航心智模型、把顶部栏变成生产力入口、收紧对话节奏。这正是飞书 / Linear / Raycast / Arc 这类「用户习惯」标杆的共同做法。

三、问题清单（按严重度）

严重度位置问题建议
高 Sidebar.tsx · TopBar.tsx 存在两套并行导航心智：顶部全局 NavKey（chat/tasks/kanban/calendar）+ 侧栏内「会话｜圆桌」分段控件，二者都改变主区却语义不同，用户易混淆。 把「会话 / 圆桌」明确为对话区两种目的地（而非全局模式），或合并进顶部导航；用 pill 分段控件 + 图标强化可发现性。
高 TopBar.tsx 顶部栏仅放折叠按钮 + 与侧栏重复的标题，浪费黄金视区。专业桌面工具普遍在此放命令入口。 加入 ⌘K 全局命令面板 + 当前上下文面包屑（如「圆桌 / 市场调研群」）。低成本、极高「符合习惯」感。
中 App.css · .message-row / .message-list 消息间距 gap: var(--space-lg)（24px）偏松，长对话滚动节奏拖沓；同发送者连续消息未分组。 将气泡间距收至 14–16px，连续同发送者消息合并间距 6px，建立清晰「轮次」节奏（对齐 iMessage / 飞书）。
中 App.css · .message-bubble.user 用户气泡背景 #ececf1 为写死十六进制，且为平涂灰、无层次，与设计令牌规范冲突。 改用令牌（如 --bubble-user 派生自 --bg-tertiary），并加极轻 inner highlight，呼应毛玻璃语言。
中 Sidebar.tsx · .sidebar-nav-item 导航项与下方会话列表的「激活态」视觉处理相同（填充背景），层级易混淆；品牌区版本号 v0.1.0 占用纵向空间。 导航激活用左侧强调条 + 浅色 pill；会话激活用浅色 pill，二者区分；版本号移入关于页或缩为角标。
中 InputBar.tsx 工具栏同时塞入 附件 / 权限 / 升级 / 上下文环 / 模型 / 语音 / 发送，窄宽下拥挤；权限默认「Ask Approval」但入口较隐。 分左簇（附件·@·升级）与右簇（上下文·模型·语音·发送），中间分隔；权限收为图标，展开才显文案；保证 44px 触控区。
低 MessageList.tsx · chat-empty 首屏标题 One Desktop, All Solutions 中英混排，建议与中文界面统一；建议项写死 4 条。 中文主标题 + 动态建议（近期文件 / 常用任务），并给一个清晰主 CTA。
低 全局 缺少可发现的键盘快捷键（⌘K / ⌘N 新会话 / ⌘B 折叠侧栏已存在），无障碍焦点管理在侧栏折叠时未显式处理。 快捷键在设置中集中展示；侧栏折叠后焦点移至主区；命令面板自带焦点陷阱。

四、视觉方向（保持并强化）

1 · 设计令牌已是资产，别动底层

Apple HIG 色板（--bg-canvas:#fafafc、--accent:#006edb）、8pt 间距、统一 1.5px 单色图标、可调毛玻璃系统——这几项构成了一致的「高级感」基础，新页面务必复用，禁止写死十六进制。

2 · 毛玻璃要「有信号」

毛玻璃的识别信号不是 blur 本身，而是更亮的半透明白 + 1px 高光描边 + 柔影。新组件（抽屉、气泡、卡片）统一走 var(--glass-surface) 系列，并设置已能在「设置 → 个性化」调节，这条链路保持。

3 · 层级靠「位置 + 亮度」而非颜色

沿用现有原则：区分来自对齐方式与表面明度，主色占比 ≤5%。圆桌群内可保留微信化绿色气泡作为语义例外，但主对话区保持克制。

五、落地优先级

P0 · 快赢（半天）

低成本 · 高回报
  • 顶部栏加 ⌘K 命令入口 + 面包屑
  • 侧栏导航与对话列表分组 + 左强调条激活态
  • 气泡间距收紧至 14–16px、连续同发送者合并
  • 用户气泡改用令牌色（去 #ececf1）

P1 · 收敛（1–2 天）

中成本 · 强体验
  • 「会话 / 圆桌」改为对话区目的地心智，与顶部导航解耦清晰
  • InputBar 左右簇分组 + 权限图标化
  • 首屏空状态本地化 + 动态建议
  • 设置页新增「快捷键」展示

P2 · 打磨（持续）

细节 · 一致性
  • 侧栏折叠焦点管理 + 动效顺滑
  • 暗色下玻璃对比复检（已含 axe 校验约定）
  • 跨页面统一卡片/抽屉圆角与阴影层级

六、立即可做的 5 个微调

  • ⌘K 占位：在 TopBar 居中放一个「搜索或执行命令… ⌘K」的胶囊按钮，先接占位逻辑，体验立刻专业。
  • 侧栏分隔：在导航区与会话区之间加 1px --border-light 分隔线，层级立刻清晰。
  • 激活态：导航激活项改为「左侧 3px accent 强调条 + 浅 pill」，与列表激活区分。
  • 间距：.message-list { gap: 14px }、.message-row.group-start { margin-top: 6px }，阅读更紧凑。
  • 气泡令牌：新增 --bubble-user: var(--bg-tertiary)，替换写死的 #ececf1。
本方案基于当前代码静态审查给出，未做可用性测试。落地时建议按 P0→P1 推进，每步保持 check:ts 与暗色/对比度校验。
