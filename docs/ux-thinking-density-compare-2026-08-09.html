密度语义（已据 Q4 定稿）：
• collapsed —— 思考层永远在场但只占一行：「模型思考中…」(live) 或「已思考 · N 步」(done)。时间线不被长推理淹没，点开才展开。这是默认档。
• peek —— 头部多一步数统计，正文以 76px 遮罩预览真实 CoT / 预测骨架，末尾「展开看完整推理」可跳到 expanded。给想看推理但又不想满屏的人。
来源诚实度（Q3）：切到「预测骨架」时，头部带 UI 预期 · 非模型原话 胶囊——非 reasoner 模型下 ThinkingLayer 用 TodoUpdate/规划派生的步骤占位，绝不明确伪装成模型原话。
状态机（Q1 chat-only）：两栏共享唯一 Turn 状态 THINKING→ACTING→WAITING→ANSWERING→DONE；圆桌模式本期不做，留待后续统一。
