# OneDesktop 中断任务「产物 / 变更 / Diff 审阅」交互体验设计（UX-021）

> 配套架构文档：`docs/run-changeset-review-design.md`（ADR-021 草案，数据层/命令/组件边界见该稿，本稿只谈**交互体验**）。
> 设计基线：Apple HIG + 现有 `.job-recover` 卡片语言（`tasks.css:363-459`）+ 单色图标规范（`Icons.tsx`，stroke 1.5px）。
> 原则：**入口收敛、渐进披露、全程不弹窗、安全操作有确认与反馈**。

---

## 1. 设计目标与原则

| 原则 | 落地 |
|---|---|
| 入口收敛 | run 卡片不堆按钮：合并为「审阅改动 ▸ N」（N=改动文件数）一个次级入口，避免挤占「继续/忽略」主操作 |
| 渐进披露 | 点开面板 → tab 选产物/变更 → 展开 diff → 版本对比 → 回滚确认，层层展开，默认零干扰 |
| 不弹窗不跳页 | 面板/确认条/diff 全部内联（滚动跟随），保留中断视图的"现场感" |
| 可扫读 | 变更行自带摘要 `+N ~M -K`，一眼看影响面（Grok 语义化摘要的轻量版） |
| 安全可逆 | 回滚二次确认 + 存档式回滚（回滚前自动留存被覆盖内容），失败 fail-closed |
| 非颜色传达 | diff 用 `+/-` 符号 + 着色双通道；selected 态用 text-primary+600（禁 accent 蓝，a11y） |

## 2. 信息架构（三层）

```
自动化页 → 中断任务视图（viewFilter=interrupted）
└─ run 卡片（现有）
   ├─ 主操作：[继续] [忽略]（existing，不动）
   └─ 次级入口：[审阅改动 ▸ N]（新增，aria-expanded）
      └─ RunChangesetPanel（内联展开，region）
         ├─ 头部：标题「本次运行的改动」 · segmented [产物 N | 变更 M] · [全部收起]
         ├─ 产物组（tab=产物）：文件卡片行（类型图标+文件名+大小 → hover 出 [预览][版本][回滚]）
         └─ 变更组（tab=变更）：文件行（▸ + 文件名 + 摘要 +N/~M/-K → [版本][回滚]）
              ├─ ▸ 行级 diff（内联：摘要行 + 红删绿增等宽代码行）
              ├─ 版本选择条（v1 v2 v3 胶囊，切换对比对象）
              └─ [回滚] → 内联确认条 → 完成/失败反馈
```

## 3. 交互流程（状态机）

```
[收起] ──点「审阅改动 ▸」──► [面板展开] ──点文件行▸──► [diff 展开]
  ▲                           │  ▲                       │ 点「版本」
  │ 点「全部收起」/再次点入口    │  │ 点▾/再点▸              ▼
  └──────────────────────────┴─┘                   [版本选择条]（diff 区切换对比）
                                                     │ 点「回滚」
                                                     ▼
                                              [确认条] ──取消──► 回到 diff
                                                     │ 确认
                                                     ▼
                                         [回滚中：按钮 loading 禁用]
                                                     ▼
                              [成功：绿 ✓ 已回滚，若有自动存档则提示可查版本历史]
                              [失败：红 ✗ 错误信息 + 重试]
```

- 展开动画：面板 `max-height/opacity` 180ms `cubic-bezier(.16,1,.3,1)`；diff 区 150ms；**不缩放不位移**（禁视差）。
- 同面板内只允许一个 diff 展开（点开新的收起旧的），版本条同理——避免"遍地开花"。
- Esc：逐级收起（diff → 面板 → 收起入口）；再次点击入口 = 整体收起。

## 4. 组件交互规格（逐元素）

### 4.1 入口按钮（run 卡片内）
- 形态：`btn btn-ghost btn-sm`，`ChevronRight` 图标 + 文案「审阅改动」+ 数量徽标 `N`（改动文件总数，产物+变更去重）。
- 状态：hover 徽标变 primary；**disabled 条件 = 该 run 无任何 changeset**（后端 `run_changesets` 返回空）。
- a11y：`aria-expanded` + `aria-controls`；展开时 chevron 旋转 90°。

### 4.2 面板头部
- 标题「本次运行的改动」+ 副标（run 会话名，muted）。
- **segmented [产物 N | 变更 M]**：复用项目对话区 segmented control 模式（chatMode session/group 同款）；selected 态 = text-primary + font-weight 600（**禁 accent 蓝底**，a11y）；`role=tablist/tab/tabpanel` + 方向键切换。
- [全部收起]：ghost 文字按钮，右侧。

### 4.3 产物卡片行（Gumloop 范式，紧凑化）
- 结构：类型图标（WriteFile/ReadFile/ListDir + 按扩展名映射）+ 文件名（等宽）+ 大小（KB/MB，round）+ 右侧 hover 操作 [预览][版本 vN][回滚]。
- **默认态只显示图标+名+大小**；hover 行高亮（bg 透明度 4%）浮出操作按钮（opacity 0→1，120ms）——保持列表呼吸感，不常驻一排按钮。
- 预览：文本/HTML → 内联展开 `<pre>`/sandbox iframe；图片 → `<img>` 缩略；其他 → 「不支持预览，可下载查看」提示。预览区同样 Esc 收起。
- 版本 vN：展开版本选择条（见 4.5），产物多版本时才有意义（同文件名多次写）。

### 4.4 变更文件行 + diff
- 结构：▸（展开指示，旋转）+ 文件名（等宽）+ 摘要 `+N ~M -K`（N 增绿 / M 琥珀 / K 删红，均带符号）+ 右侧 [版本 vN][回滚]。
- **diff 容器**：`bg-canvas` 浅底 + 1px border，内衬 12px；顶部摘要行「+N ~M -K · 共 X 行改动」；代码行 12px `--font-mono`。
  - 删行：`-` 前缀 + 红底（`--diff-del`）；增行：`+` 前缀 + 绿底（`--diff-add`）；上下文：中性，缩进对齐。
  - **大文件退化**（>2000 行 / >500KB）：容器内显示「文件过大，请在编辑器中查看」+ [在编辑器中打开]（调用系统编辑器/Reveal in Finder，后续演进）。
- 摘要数字用 `Math.round`；同文件版本间对比时摘要改为两版本差值。

### 4.5 版本选择条
- 形态：diff 容器上方一行胶囊 `v1 v2 v3`（选中 = text-primary+600 边框加深；历史版本 muted）。
- 交互：点击切换 diff 对比对象（当前选中版本 vs 前一版本）；`auto_snapshot` 记录带 `存档` 小标记（琥珀点）。
- 收起：与 diff 绑定（收起 diff 即收起版本条）。

### 4.6 回滚确认条（危险操作，安全设计核心）
- 触发：点 [回滚] → **该行内联**滑出确认条（不弹窗、不遮罩）：「将恢复为改动前内容。确定？」+ [回滚]（红填充，danger 语义）+ [取消]（ghost）。
- 确认中：按钮变「回滚中…」+ disabled，**防重复提交**。
- 成功：确认条替换为绿底反馈行「已回滚」+ 若触发存档式回滚追加「已保留被覆盖的修改，可在版本历史中查看」（2s 后淡出，或保留为可关闭行）。
- 失败：红底反馈行显示错误 + [重试]；**失败即停**（fail-closed，不做自动重试）。
- a11y：确认条为 `role=dialog`（非模态，focus 陷阱无需）——或降级为 `alert` region；焦点移入 [回滚]；Esc = 取消。

## 5. 视觉与动效（令牌映射）

| 元素 | Light token | Dark（`[data-theme="dark"]`） |
|---|---|---|
| 面板容器 | `--bg-elevated` + `--border-default` + `--radius-lg` | 透明白 `rgba(255,255,255,.08)` |
| 文件行 | `--bg-canvas` + border | 透明白 `.06` |
| diff 容器 | `--bg-canvas` | 透明白 `.04` |
| diff add | `rgba(27,161,104,.12)` 底 + 绿 800 字 | `rgba(27,161,104,.16)` 底 + 浅绿字 |
| diff del | `rgba(220,76,72,.10)` 底 + 红 800 字 | `rgba(220,76,72,.16)` 底 + 浅红字 |
| 回滚按钮 | danger 语义填充 | danger 语义填充（dark 提亮一档） |
| 确认条 | `--status-warning` 淡底 | 琥珀透明白 |

- 新增 CSS 前缀 `.run-cs-*`（run changeset），独立于 `.job-recover-*`，避免样式串扰。
- 动效：展开 180ms 缓入缓出；操作按钮 fade 120ms；**全部尊重 `prefers-reduced-motion`**。
- 图标：新增 `Icons.Diff`（两行 +/−）、`Icons.History`（版本，时钟回环）、`Icons.Undo`（回滚，或复用 Refresh 倒带）；均为单色 1.5px，禁彩色 emoji。

## 7. 可访问性清单（WCAG AA）

- 键盘：Tab 顺序 = 入口 → 面板头部 → 文件行 → 操作；Enter/Space 展开，Esc 逐级收起，方向键切 tab/版本。
- diff 双通道：`+/-` 符号 + 着色；摘要数字含符号。
- 对比度：文件行文字 text-primary（≥7:1）；muted 元信息 ≥4.5:1；diff 红/绿 800 字 on 12% 底（改色跑 `node scripts/axe-probe.mjs`）。
- 焦点管理：展开/收起后焦点留在触发元素；diff 区可聚焦（tabindex=0）供朗读。
- 动效：`@media (prefers-reduced-motion: reduce)` 禁用展开动画（直接显示）。
- 语义：面板 `role=region` + `aria-label`；tab 用 tablist 模式；确认条 `aria-live=polite`。

## 10. 待拍板决策（实现前确认）

1. **入口形态**：A「审阅改动 ▸ N」单按钮 + 面板内 tab（推荐，本稿默认）；B 产物/变更双按钮直开对应 tab。
2. **确认条**：内联行级确认（推荐，本稿默认）vs 全局轻弹窗（`.modal*` 体系）。
3. **产物预览**：MVP 只做文本/HTML/图片内联（推荐）vs 全类型（PDF/表格，成本高）。
